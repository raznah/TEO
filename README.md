# Tyrian Economic Optimizer

Current Release

v0.1.0 Foundation

## Vision

TEO is a desktop application designed to answer one question:

> What is the most profitable thing I can do in Guild Wars 2 right now?

The application will eventually include:

- Fishing
- Trading Post
- Crafting
- Gathering
- Currency conversion
- Meta events
- Route optimization
- Achievement tracking

---

This project is currently under active development.
