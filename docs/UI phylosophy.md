# UI Philosophy

## 1. One panel, one question

Every dashboard panel answers a single question.

Examples:

🎯 Recommendation
"What should I do today?"

🎉 Festival
"What festival is active?"

🎣 Daily Fishing
"What is today's Daily Catch?"

---

## 2. Question → Answer

Information is always presented in the same order.

Label

Answer

This consistency allows users to scan the dashboard quickly.

---

## 3. Scout speaks clearly

Scout provides concise recommendations.

He explains his reasoning without overwhelming the player.

---

## 4. Link to authoritative sources

TEO provides guidance.

Detailed reference information lives on the Guild Wars 2 Wiki.
