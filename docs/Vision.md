 Tyrian Economic Optimizer (TEO)

## Vision

TEO is a decision support system for Guild Wars 2.

Its purpose is to help players answer one question:

> Given my account, my available time, and today's economy, what is the best thing I can do right now?

The project aims to provide recommendations based on data rather than opinion.

TEO is built around practical gameplay experience, verified game mechanics, and current market information.

Every feature added to TEO should help players make better decisions.

If a feature does not improve decision-making, it should be reconsidered.
