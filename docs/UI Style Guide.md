# UI Style Guide

## Purpose

This document defines the visual language of TEO.

The goal is to provide a clean, consistent, and welcoming experience.

---

## Design Principles

### Calm

Avoid clutter.

The interface should reduce cognitive load.

---

### Information First

Important information appears before supporting details.

---

### Consistency

Buttons, navigation, colors and layouts should remain consistent throughout the application.

---

### Explainability

Every recommendation should explain why it exists.

---

### Friendliness

The application should feel like a helpful companion.

Example greetings:

"Good morning, sunshine!"

"Ready for another adventure?"

---

## Dashboard Philosophy

The dashboard answers questions.

It should never feel like a spreadsheet.

Every widget must answer one specific question.

---

## Theme

Primary inspiration:

Guild Wars 2

Not by copying ArenaNet's artwork, but by capturing the feeling:

Elegant

Warm

Professional

Minimal
